# BuddyNeko：Agent のための猫型デスクトップインターフェース

BuddyNeko は、M5Stack CoreS3 StackChan 向けのコミュニティ Buddy デザインである。CoreS3 を猫型のデスクトップ端末にし、ホスト Agent が AI、STT/TTS、ツール呼び出し、認可ポリシーを担当し、デバイスが表情、タッチ、カメラ、音声、LED、サーボ動作を担当する。現在のファームウェアバージョンは v0.7.0 である。

## 背景と目標

Agent がテキストだけを返す場合、コーディング中、思考中、承認待ち、完了、失敗といった状態をデスク上で感じ取りにくい。BuddyNeko はそれらの状態を実体デバイスへ投影しつつ、ESP32 ファームウェアの責務を小さく保ち、ビルド、デバッグ、ホスト Agent の交換をしやすくする。

複雑な推論はホスト側に置く。ホストがモデル呼び出し、ツール実行、認可ポリシーを担当し、StackChan は Call Buddy プロトコルで状態を表示し、タッチ、音声、センサーイベントをホストへ返す。

## 設計と実装

Call Buddy は行単位のテキストコマンドと JSON Lines イベントを使う。USB Serial は 115200 baud で動作する。Wi-Fi を設定すれば、TCP で同じコマンドとイベントを扱い、同じ接続で半二重 PCM16 音声も転送できる。

ファームウェアには、状態機械、16 色の猫スプライト、タッチ処理、RGB エフェクト、サーボ制御、カメラによる動き追跡、ディスプレイキャプチャを含む。開発ホストは USB Serial から短時間のリースを明示的に要求し、更新しなければならない。リースが切れるとデバイスはデプロイ用ホストへ戻る。

## 現在の機能

- CoreS3 の画面に 16 色の猫アニメーションを表示する。
- Call Buddy で idle、listening、thinking、speaking、coding、approval、done、error などの状態を制御する。
- USB Serial、任意の TCP、タッチ操作、承認応答、サーボ動作、RGB エフェクトに対応する。
- カメラで低頻度の動きを追跡し、必要に応じて視覚フレームをホストのエンドポイントへ送る。
- マイクとスピーカーの音声を半二重 PCM16 で転送し、音声処理をホスト側に置く。
- アセット生成、画面キャプチャ、開発ホストのリース維持に使う、外部依存のない Python ツールを提供する。

## 境界とトレードオフ

BuddyNeko はコミュニティデザインであり、M5Stack 公式の出荷ファームウェアでも Xiaozhi ファームウェアでもない。デバイス上で高レベル AI は動かさず、表示、入力、制限された動作だけを扱う。

タッチによる承認イベントはユーザーの意図だけを表す。最終的な認可はホストのポリシーが担う。USB 給電だけで開発ホストを自動選択することはなく、サーボ動作もファームウェアの安全範囲に制限する。対象は信頼できるローカルまたは LAN 環境であり、デバイスプロトコル自体は完全な認証層ではない。

## 状態と次のステップ

BuddyNeko は開発中であり、ファームウェアは実機の CoreS3 StackChan 向けにビルドできる。次は独立した Agent Host との接続を引き続き整え、表情、動作、音声、承認を Agent ワークフローの安定した構成要素にすることである。
