# 实验：用 Hanami CLI 验证 Agent 直接调用工具的边界

Hanami CLI 是一个抓取樱花预计开花日期并更新展示页面的小型实验。它把传统 CLI 与 Agent Skill 组合起来，测试 Agent 是否可以在一个具体工作流中直接调用工具，而不必先把每个动作包装成 MCP Server。公开材料只记录了本地 OpenClaw 环境中的验证结果。

## 问题

这个实验比较两种工具接入方式：Agent 直接调用带有 Skill 描述的 CLI，和通过 MCP 协议调用工具。问题不是证明 CLI 在所有场景中能取代 MCP，而是确认一个简单的季节数据抓取流程能否用更轻的接口完成。

## 方法

CLI 从天气预报网站抓取樱花预计开花日期，再同步更新一个简单的展示网页。Skill 描述调用边界与使用方式，让本地 Agent 能够发现并运行 CLI。由于实现仓库和具体接口没有公开，本文不补充未记录的抓取策略、页面结构或测试数据。

## 结果

作者记录的结果是：该流程在本地 OpenClaw 环境中测试跑通。这说明在这个受限工作流中，CLI + Skill 的组合具备可行性，但没有证明它在复杂工具编排、权限控制、协议兼容或其他 Agent 环境中可以替代 MCP。

## 局限

目前没有可访问的公开代码仓库、运行日志、测试样本或与 MCP 的对照指标。因此无法复核抓取稳定性、季节数据更新策略、失败处理和长期维护成本。

## 后续影响

这张卡片在路线图中标记为已完成。公开记录没有给出下一步实现；可确认的结论只限于：在本地 OpenClaw 环境中，传统 CLI 配合 Skill 可以完成这个具体流程。
