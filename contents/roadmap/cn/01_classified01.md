# 机密实验：基于 Azure AI Foundry 的 Agent 应用

这是一条经过脱敏的内部实验记录。公开版本只能确认实验涉及多 Agent 协作、MCP 调用、RAG 检索和结果质检；业务名称、协议细节、编号、数据集和效果指标均已删除。

## 问题

实验关注的是：能否在 Azure AI Foundry 上把工具执行、专家协作检索、知识库和 Agent 之间的结果检查组织成一个可运行的应用。公开记录不足以确认具体业务目标或评估标准。

## 方法

记录中可公开的实现包括以下部分：

- 用 FastAPI 构建 App，让 Agent 生成 Python 脚本，再通过已脱敏的 MCP 协议执行脚本。
- 用多个专家 Agent 分工：一个把模糊需求和脱敏编号转换为搜索指令，一个负责检索，另一个负责整理结果并在资料不足时请求补充检索。
- 在一个脱敏功能中加入 RAG 知识库，让 Agent 在回答前检索内部 know-how，并通过 Agent 之间的检查判断回答是否引用了这些知识。
